# Contributing to software-architecture-tools

First off, thanks for taking the time to contribute! 🎉

The following is a set of guidelines for contributing to **software-architecture-tools**. These are mostly guidelines, not rules. Use your best judgment, and feel free to propose changes to this document in a pull request.

## How Can I Contribute?

### Reporting Bugs

This project is a curated list, so "bugs" are usually:
- Broken links.
- Tools that are no longer free or have changed significantly.
- Incorrect descriptions.

Please open an Issue with the details.

### Suggesting New Tools

We love new suggestions! To keep the list high quality, please ensure the tool meets these criteria:
1. **Web-based:** Prefer tools that don't require local installation.
2. **Free/Freemium:** Must have a usable free tier.
3. **Architectural Value:** Must be relevant to software architecture or design.

### Your First Code Contribution (Pull Requests)

1. Fork the repo.
2. Create a new branch for your changes.
3. Make your changes to `README.md`.
4. **Sort alphabetically:** If you add a tool to a category, please keep the list sorted alphabetically.
5. **Check links:** Ensure the URL works.
6. Commit your changes and open a PR.

## Style Guide

- **Consistency:** Follow the existing table format.
- **Concise Descriptions:** Keep descriptions clear and under two sentences.
- **No Marketing:** Avoid "marketese"; focus on what the tool *does*.

Thanks for making this list better! 🚀
